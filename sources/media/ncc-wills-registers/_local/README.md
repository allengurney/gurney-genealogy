# NCC will-registers — local-only masters

Full-resolution FamilySearch register images for the Norwich Consistory Court
(NCC) will registers and act books, keyed to sourceId `ncc-wills-registers`.

**Why `_local`:** FamilySearch full-resolution image downloads (subject to
FamilySearch terms of use); kept as working-reference masters off GitHub.

**Retrieval:** each filename carries its FamilySearch `3:1:` ark and/or the film
DGS + image number (e.g. `jekkys8470476-img366-…` = DGS 008470476 image 366;
`ncc8076270-img300-aleyn-fo19r-…` = DGS 008076270 image 300). Re-pull via the
das/v2 recipe in `.claude/skills/familysearch-fulltext-research/SKILL.md` §3.

Notable contents: the Jekkys-211 Thomas Gurnay will complex 1471 (img364–367,
packet 51); the Aleyn act-book fo. 19 Thomas Gurnay admon 1454 (ncc8076270
img251–301, packet 49); the 1456–1471 NCC registered-will Gurney-passage leaf
(`ncc-regd-wills-vol9-10-1456-1471-…`, packet 45 — re-stage lead L-249).
