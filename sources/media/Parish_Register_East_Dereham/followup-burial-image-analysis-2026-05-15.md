## Visual impressions

- Page 00725 Marye relationship token: the tightened panel keeps the lower Marye line isolated and magnifies the word/strokes between `Marye` and `of ffrancis`. The token remains damaged/contaminated by bleed-through. It does not cleanly resolve to `daughter`; a shorter relationship token remains plausible, but the crop should be treated as unresolved rather than extracted as a firm relationship.
- Page 00725 Marye month token: the tightened panel supports the line-level reading of `ffrancis Gurny` followed by a month/date ending in `25`. The month remains interpretive. The stroke rhythm is compatible with `January`, but not crisp enough to promote above an inferred reading.
- Marye 1618 anchor: the local `gbprs_norfolk_pd_86-41_00736.jpg` image is a visible 1620 page, not the May 25 Marye/ffrancis line. The May 25 Marye line in the current local images resolves to page 00732. The focused 00732 sweep supports `Marye the daughter of ffrancis Gurnoe bapt may 25`; father attribution to `ffrancis` is strong, while the surname terminal is best carried as interpretive `Gurnoe`.
- Page 00715 John Entry E: `site/website/media/east-dereham/john_gurney_715_enhancement_sweep_v1.png` is useful but uses the older broad enhancement format. The new `page_00715_entry_e_john_six_state_sweep.png` rebuilds Entry E from the retained line crop `site/website/media/east-dereham/line_05_enh_x3.png` into the same six-state evidence standard as the current cluster.
- Page 00721 Edward entry: the new sweep expands the evidence from terminal-only surname inspection to the full Edward son-of-ffrancis line. It remains a useful same-hand comparator for `ffrancis`, the `Gurn-` body, and terminal variation.
- Pages 00733-00735 negative pass: row-strip contact sheets were created for a line-level visual scan. No missed Gurney/Gurnie/Gurny/Gurnoe entry was flagged in these strips. Page 00735 contains some `ffrancis` entries, but the visible surnames are non-Gurney forms. Treat this as "no candidate flagged in the line-strip pass," not proof of absence under all possible imaging conditions.

## Source-number caveat

The local page numbering does not behave exactly as the earlier target wording implied. In this file set, the 1618 Marye/ffrancis christening anchor is on 00732, while 00736 is a 1620 page. The follow-up artifacts preserve both facts: a six-state sweep for the actual local Marye/ffrancis line and a context image documenting the 00736 mismatch.
