This is not the burial target, but it is useful handwriting and family-cluster context for later comparison; see `page-00732-marye-ffrancis-gurnoe-terminal-analysis.md`.

A later deeper pass did not support my broad-pass wording that one Cooke-wife line was an unrelated Margaret entry; see `page-00725-deep-analysis.md`.
