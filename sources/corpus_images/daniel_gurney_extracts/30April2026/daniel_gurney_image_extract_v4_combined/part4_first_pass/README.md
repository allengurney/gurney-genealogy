# Daniel Gurney Part IV Image Extract - First Pass

This package contains a first-pass extraction of images from the uploaded Part IV/later-lines PDF of Daniel Gurney's *Record of the House of Gournay*.

## Contents

- `images/` - 27 cropped grayscale PNG images.
- `catalog/daniel_gurney_part4_image_catalog.md` - structured markdown catalog with source page, caption, associated people, places, scope judgment, and adjacent-text description.
- `catalog/contact_sheet.png` - visual contact sheet for quick review.
- `manifest.json` - machine-readable version of the catalog.

## Source

`Record of the House of Gournay_logical_part_3-Later Lines and Appendix.pdf`

## Processing

Images were rendered at 300 dpi, cropped closely, converted to grayscale, and lightly auto-contrasted. No generative enhancement or major image cleanup was applied.

## Review notes

This is a first-pass extraction. The entries marked `Contextual / retained` or `Cataloged / retained, lower-confidence relevance` should be reviewed before being treated as site-ready illustrations. The stronger candidates are the Robert de Gournay letter/seal, Beverstone Castle, Richemounte Castle, St. Mark's Chapel and Gournay/Gaunt monument images, Sibilla de Gournay's seal, Matthew de Gournay's seal, Berkeley Castle, Barew Court, and Barew Gurney Church.
