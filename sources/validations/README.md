# sources/validations/

Per-source validation worksheets. One file per source that has been examined closely enough to record the analysis.

## Naming

Matches the `sourceId` in `data/sources.json`, e.g.:

- `nro-pd-12-1.md` — St Martin at Palace marriage register, Francis Gurney + Margaret Rybett, 1611.
- `nro-pd-86-41.md` — East Dereham register, including the four-test paleographic analysis of Entry E.
- `anderson-gmd-2015.md` — *Great Migration Directory* entry for John Gurney-1.

## Contents

Each worksheet captures: what was examined, what was concluded, what remains uncertain, and pointers to the media (via `sources/media-refs.md` → OneDrive) that supports the analysis. These are the audit trail behind citations.
