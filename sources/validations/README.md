# sources/validations/

Per-source validation worksheets.

## Purpose
Record:
- what source was examined
- what portion was examined
- how it was examined
- scope limits
- where findings landed

## What these files are not
They are not the main home for biographical or topical findings.

## Naming
Match the `sourceId` in `data/sources.json`.
