# Preferred footnote templates

## Book or compiled work
[^1]: Author Name, *Full Title* (Place: Publisher, Year), page or entry. URL if available. Source ID: example-source-id.

## Archival or parish register
[^2]: Repository Name, collection or register title, reference number, specific entry/page/folio/image detail, event description, date if known. URL if available. Source ID: example-source-id.

## Website or article
[^3]: Author or organization, “Full Page Title,” site name, publication or update date if known, URL (accessed Month Day, Year if needed). Source ID: example-source-id.

## Multiple-source claim
Text of sentence.[^4] [^5]

[^4]: Full citation for first source. URL if available. Source ID: first-source-id.
[^5]: Full citation for second source. URL if available. Source ID: second-source-id.

Delimit multiple source footnotes with a space

## Notes

- Replace placeholder numbering with the file’s normal footnote numbering pattern.
- If the renderer or file conventions require a different style, preserve compatibility.
- Keep note text human-readable.
- Avoid unexplained shorthand like “DG-I-278” as the entire visible note.
