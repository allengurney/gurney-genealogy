# research/people/

One file per person. Files accumulate what we know, what we're investigating, and what's been ruled out.

## Naming

`g{NN}-{first-last}.md` for direct-line ancestors, where NN is the zero-padded generation number. Examples:

- `g13-john-gurney-1.md`
- `g14-francis-gurney.md`
- `g14-margaret-rybett.md` — spouses get their own file when there's substantive research about them, not just a mention in the spouse's record
- `g17-anthony-gurney.md`

For people whose relationship to the direct line is unresolved or who are collateral but research-relevant, use a descriptive slug without a generation prefix:

- `hingham-ann-gurney.md` — possible sibling of John Gurney-1
- `francis-gurney-laceweaver.md` — the other Francis (disambiguation target)
- `earsham-john-girney-1636.md` — candidate match

Two people sharing a generation get separate files. Don't combine.

## Structure inside the file

Consistent sections aid navigation. Use these headings as applicable:

```
# {Name}

{One-line summary: relationship to direct line, dates, geography}

## Known facts
Facts with sourceId citations. This is the durable record.

## Open questions
What we're trying to resolve.

## Records examined
Source-by-source notes on what was looked at and what was found. Link to sources/validations/{sourceId}.md for the deep paleographic or analytical work.

## Negative results
Searches that returned nothing, absences that are themselves informative. First-class findings.

## Conjectures
Hunches, working hypotheses, things to pressure-test. Clearly labeled as not-yet-established.

## Crosslinks
→ topics/...
→ places/...
→ case-files/...
```

Not every file needs every section. Start with what applies; add sections as the file grows.
