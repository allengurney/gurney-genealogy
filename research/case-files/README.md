# research/case-files/

Long-form investigations of contested or complex questions. Each case file is versioned and self-contained: timeline, bibliography, evidence analysis, probability assessment (where appropriate), and open items.

## Active

- `candidate-b.md` — the leading hypothesis for John Gurney-1's English origin: son of Francis Gurney (Merchant Taylor) and Margaret Rybett.

## Convention

Case files cite `sources.json` IDs rather than re-stating full citations inline. When a case file's conclusions stabilize enough to affect a fact sheet, the fact sheet is updated and the case file continues to hold the full argumentation.
