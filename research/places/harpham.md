# Harpham, Norfolk, England

## Status of this place record

This file should currently be treated as a **provisional / suspect place record**, not as a secure family place on the same footing as Harpley, Hardingham, Hingham, or West Barsham.

The reason is explicit in the **Henry Gurney (G15) research companion**, which notes under "Friction with the project JSON" that **"Harpham" should be "Harpley"** and that there is no clear Harpham in north-west Norfolk matching the family context. [Henry G15 companion] That is a strong enough warning that the project should not keep building a confident historical narrative around Harpham as though it were already verified.

## Why this file still exists

The structured place layer currently retains a separate **Harpham** record with the description "Harpham manor, purchased in 1587 and reflected in later church presentations." [current place registry] But the same Henry G15 research companion that underlies much of the later Tudor Norfolk place work argues that this should likely be **Harpley**, the ancestral manor repurchased in 1587, rather than a distinct place called Harpham. [Henry G15 companion]

Until the structured layer is corrected, this file serves as a **holding pen for a likely normalization or data-entry error**.

## Best current interpretation

The safest current interpretation is:
- the 1587 repurchase associated with **Henry Gurney (G15)** belongs to **Harpley**, not Harpham; [Henry G15 companion]
- the current `harpham.md` and related structured record are therefore likely duplicative or erroneous; [Henry G15 companion]
- the real historical narrative for the manor should be carried in **`research/places/harpley.md`** unless and until separate evidence for a true Norfolk Harpham connection is found. [Harpley file]

## Why this matters

This is exactly the kind of issue the current place-file review is meant to catch. The structure may be cleaner than before, but we still need the content layer to challenge bad inherited place distinctions rather than merely decorating them.
