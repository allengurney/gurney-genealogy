# East Dereham AI-assistant procedure — retired from publication

`east-dereham-ai-assistant-procedure.md` was published at
`/key-research/east-dereham-ai-assistant-procedure.html` until 1 August 2026. It set out the
machine-assisted paleographic workflow behind a reading of the East Dereham register that has
since been withdrawn, and it was removed from the site so that no public page presents that
reading as a finding.

**Why it is kept.** It is the only full record of how the reading was produced, and the failure
mode it illustrates — a confident, internally consistent machine reading of a damaged hand,
adjudicated on the wrong line of the wrong image — is the reason the project now requires a
positive control on every sweep and a register image before any variant question is settled.

**How to treat it.** As a record of method, never as evidence. The current position on the East
Dereham register is in the case file (fifth edition, §5), in
`research/topics/east-dereham-parish-register-paleography.md`, and in the deviation audit at
`research/people/g13-john-gurney/topics/identity/32-norfolk-parentage.md`.

**What moved with it.** The eleventy front matter was replaced with a plain header, and the
redirect stub at `site/website/redirects/east-dereham-ai-assistant-procedure.html.md` was
deleted. The images the page displays remain in `site/website/media/east-dereham/`, which other
generated pages still use.
