# research/topics/

Cross-cutting problems, methodological threads, and analytical frames that span multiple people and places. When a question doesn't fit cleanly under one person or place, it goes here.

## When to create a topic file

Use a topic file when:

- The problem touches three or more people or places (the two-Francis disambiguation affects Francis G14, Francis the laceweaver, and every London baptism in the period).
- The question is methodological rather than biographical (how to interpret Anderson's "Unknown" origin designation; what Ancestry's Norfolk collections actually draw from).
- There's an analytical principle worth preserving separately from any specific investigation.

If a problem is confined to one person, it belongs in that person's file under Open Questions. If it grows to touch others, promote it to a topic.

## Naming

Kebab-case, descriptive, specific:

- `two-francis-disambiguation.md`
- `anderson-1636-vs-weymouth-1641.md`
- `protestation-returns-coverage.md`
- `ancestry-norfolk-collections-scope.md`
- `boyd-marriage-index-reliability.md`

## Structure

Looser than people/ or places/ — topics vary more in shape — but typically:

```
# {Topic}

## The problem
What the question is, why it matters.

## Current state
Where the thinking is. What's been established, what's still open.

## Evidence / analysis
The substantive content.

## Implications
Where this affects fact sheets, case files, or other research.

## Crosslinks
→ people/... (the specific people affected)
→ places/... (the specific places affected)
→ case-files/... (if it feeds a larger case)
```
