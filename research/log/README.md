# research/log/

Chronological research session logs. One file per active day, named `YYYY-MM-DD.md`.

## Purpose

When something surfaces during a working session that's worth preserving but doesn't yet belong in a fact sheet, case file, or source validation, it goes here. Small entries, written as they occur. The log is the safety net against losing context between sessions.

## Format

Each entry is a short block with a timestamp (optional, roughly hourly is fine), a heading, and the observation. Examples:

- A tangential finding that doesn't belong in the current investigation.
- A Daniel Gurney quote worth remembering.
- A search that returned nothing useful (negative results are first-class findings).
- A question to revisit.

Log entries are a raw trail, not polished prose. Later review distills them into case files, source validations, or fact sheet revisions as appropriate.
