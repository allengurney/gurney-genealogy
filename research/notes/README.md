# research/notes/

Atomic observations organized by topic, not by date. Where `log/` is chronological, `notes/` is thematic.

## Examples

- `rivett-geographic-cluster.md` — the Garveston/Gressenhall/Shipdham/St Martin at Palace cluster and its relevance to Candidate B.
- `two-francis-problem.md` — the Merchant Taylor vs. laceweaver disambiguation, applicable to all London Gurney baptisms in the period.
- `anderson-1636-vs-weymouth-1641.md` — the outstanding arrival date discrepancy.

## When to use a note vs. a case file

If the topic fits on one screen and doesn't require a probability assessment or multi-source timeline, it's a note. If it's a sustained argument with evolving evidence, it's a case file.
