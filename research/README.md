# research/

Working material — the research process, not the polished outputs. Case files, chronological session logs, and atomic notes live here.

## Subfolders

- `case-files/` — long-form investigations of contested questions (e.g., John Gurney-1's English origin). Each case file is a self-contained document with its own bibliography, timeline, and analysis.
- `log/` — chronological research session logs, one file per active day (`YYYY-MM-DD.md`). A running trail of what was looked at, what was found, what didn't pan out, and what's next.
- `notes/` — atomic observations too small for a case file but worth preserving. A stray Daniel Gurney quote, a hunch about a place name, a record that turned out to be the wrong Francis. Named by topic.

## Why this exists

Conclusions without reasoning trails are brittle. When a finding needs to be defended, revised, or extended months later, the log and notes are what prevent rebuilding context from memory.
